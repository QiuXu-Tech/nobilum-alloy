# CPU 激活卸载最小实机探针

实验日期：2026-11-10。摘要公开日期：2026-11-11。

## 问题与范围

本次比较同一模型、同一短输入下，GPU 常驻计算与选择性 CPU 激活卸载的前后向资源开销。它用于判断一种 CPU/GPU 协作方式在当前小负载下的代价，不评估模型质量或教师优势。

本摘要由项目保留的实验记录及项目内独立复核记录整理；不是外部第三方复现。本次仅公开汇总，完整脚本、输入与原始张量未随本文发布，读者暂不能仅凭本仓库完整复现。

## 测试条件

- 设备：RTX 5070 Laptop GPU，8GB 显存；主机内存 64GB，Windows 环境。
- 模型来源：Qwen/Qwen3.5-2B，固定修订 `15852e8c16360a2fea060d615a32b45270f8a8fc`。此为源 checkpoint 的名称，不表示已经裁出一个同名大小的文本学生。
- 模型路径：NF4 量化、BF16 计算；144 个 FP32 LoRA 张量，共 4,718,592 个适配参数。
- 输入：单条 8-token 字面输入。训练目标使用人工构造的全词表概率分布，不使用真实教师输出。
- 对照：GPU 常驻与选择性同步 pinned-memory CPU 激活卸载；每种方式预热一次，再记录三次前后向。
- 优化器更新次数为 **0**；本次不执行结构裁剪或质量评测。

## 结果

| 指标 | GPU 常驻 | CPU 激活卸载 |
|---|---:|---:|
| 三次前后向耗时（秒） | 0.286530 / 0.255741 / 0.294117 | 0.473651 / 0.531596 / 0.432766 |
| 前后向耗时中位数（秒） | 0.286530 | 0.473651 |
| 张量 allocated 峰值（字节） | 3,263,168,000 | 3,139,631,616 |
| 张量 reserved 峰值（字节） | 3,284,140,032 | 3,162,505,216 |

以 allocated 峰值计算，卸载节省 **123,536,384 字节，即约 117.8 MiB（3.79%）**；前后向耗时中位数增加约 **65.3%**。所检查的梯度与选定 logits 的最大绝对差均为 **0**。

## 测量边界与未完成事项

耗时排除预热及模型加载，不是端到端作业时间。首个 GPU 常驻预热耗时约 16.23 秒；成功修复执行从派发到自有资源清理约 33.83 秒。表中显存是框架张量 allocated/reserved 口径，不是整个进程、驱动或桌面的总显存。

本轮存在一次早期失败：模型加载和准备返回后，诊断 JSON 写出失败，尚未进入前后向。该失败记录保留；表中数值来自后续修复执行，不能据此声称整轮从未失败。

单输入、三次重复和零优化器更新不足以推断长序列、批量训练、完整优化器状态或持续训练吞吐量。差值为零只覆盖本次检查的数值对象，不证明任意输入下等价，也不证明模型质量改善。

## 当前结论

对这次极短负载，GPU 常驻是测得更快的路径；选择性 CPU 激活卸载以额外耗时换取了有限的显存节省。因此，本次结果支持在该负载下优先 GPU 常驻，将 CPU 激活卸载保留为容量受限时的候选方案。

这项结论不外推到其他硬件、模型或完整训练流程。后续研究与是否公开更多材料，按实际结果另行决定，不构成发布计划。
